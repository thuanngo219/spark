# Đo animation và editor Spark — 26/10/2026

## Phạm vi và cách đo

Đo 5 cảnh báo layout-transition: margin h1, chiều cao eyebrow, chiều cao thống kê, width/padding nhãn dự án, width thanh tiến trình. Ba rule header đo chung vì cùng một tương tác thu/mở. Chrome trên macOS, bản Next.js production local; viewport 1280×844 và 390×844, 60 task mẫu có project, CPU slowdown 4× qua CDP. Mỗi trường hợp chạy 1 lượt làm nóng rồi 3 lượt thu mẫu 450ms. Không dùng dữ liệu cloud thật.

Header kích hoạt bằng scroll thật của trang; nhãn dự án bằng click control DOM thực tế. Thanh tiến trình là phép đo cô lập: thêm một track cùng class CSS hiện hành, animate 10↔90%; không phải phép đo toàn bộ startup hoặc tốc độ sync. Frame interval lấy requestAnimationFrame; LayoutDuration lấy chênh lệch CDP Performance metrics trong cửa sổ đo. Không phải Core Web Vitals hay profiler Safari/iPhone.

Baseline: commit 4cf1ff2. After: bản sửa focus/touch D-166; các rule animation không đổi. Chênh lệch giữa hai lần đo là biến thiên môi trường, không được coi là cải thiện do tối ưu animation. Lần after hoàn tất trước điều chỉnh cuối cùng của touch guard cho vùng chọn rỗng; thay đổi đó chỉ chạy trong editor, không liên quan các tương tác đo ở đây.

## Kết quả trước / sau

Frame p95 và LayoutDuration là trung vị của 3 lượt. Max frame là lớn nhất, số frame >25ms cộng cả 3 lượt; bỏ frame đầu tiên của mỗi cửa sổ.

| Tương tác | Frame p95 ms | Max frame ms | Tổng layout ms/cửa sổ | Frame >25ms |

| Header (3 cảnh báo) · 1280px | 16.8 / 16.7 | 33.3 / 16.8 | 20.16 / 11.47 | 1 / 0 |
| Nhãn dự án · 1280px | 16.7 / 16.8 | 16.8 / 16.8 | 38.53 / 35.12 | 0 / 0 |
| Thanh tiến trình (tách riêng) · 1280px | 16.7 / 16.8 | 16.8 / 16.8 | 0.42 / 0.10 | 0 / 0 |
| Header (3 cảnh báo) · 390px | 16.7 / 16.7 | 16.8 / 16.8 | 16.73 / 11.39 | 0 / 0 |
| Thanh tiến trình (tách riêng) · 390px | 16.7 / 16.8 | 16.8 / 16.8 | 0.69 / 0.22 | 0 / 0 |

Header và nhãn dự án thực sự tạo layout trong animation, nhưng phép đo này không cho thấy giật kéo dài. Giữ chuyển động/typography đã duyệt; chưa thay bằng transform/grid hoặc suppress rule layout-transition. Một frame 33.3ms ở baseline header desktop không đủ để kết luận lỗi ổn định. Không suy ra 60/120fps trên iPhone 17 từ kết quả Chrome desktop.

## Editor

Nguồn Tiptap đang cài gọi autofocus trong setTimeout; regression xác nhận ở bản cũ editor chưa focus trong cùng sự kiện click Sửa. Bản mới mount bằng flushSync trong click và gọi focus/selection cuối tài liệu trực tiếp, không autofocus trì hoãn. Keyboard vẫn do iOS quyết định; chưa xác minh trên thiết bị thật.

CSS overscroll đơn thuần chưa đủ cho phản hồi nội dung ngắn trên iPhone. Thêm touch guard phạm vi backdrop trong focus mode mobile: ngăn vuốt dọc khi không có scroll range hoặc vuốt ra ngoài biên, giữ cuộn vào trong, pinch và chọn chữ. Bài test kiểm tra cancellation của touchmove, CDP touch swipe, nội dung rỗng/ngắn/dài, lưu/hủy và cleanup. Không tuyên bố tái hiện được rubber-band của iOS bằng Chrome.

Nguồn kiểm chứng nền tảng: [WebKit overscroll với nội dung không đủ cuộn](https://bugs.webkit.org/show_bug.cgi?id=244232), [WebKit focus và keyboard ngoài user gesture](https://bugs.webkit.org/show_bug.cgi?id=195884). Bản Tiptap cục bộ: node_modules/@tiptap/core/src/Editor.ts và commands/focus.ts.
