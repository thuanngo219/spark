# Inter 4.1

Vendored, unmodified WOFF2 variable fonts from the official tagged release:

- https://github.com/rsms/inter/tree/v4.1
- https://raw.githubusercontent.com/rsms/inter/v4.1/docs/font-files/InterVariable.woff2
- https://raw.githubusercontent.com/rsms/inter/v4.1/docs/font-files/InterVariable-Italic.woff2
- https://raw.githubusercontent.com/rsms/inter/v4.1/LICENSE.txt

SIL Open Font License 1.1: see LICENSE.txt. Both normal and italic expose weight 100–900. Root layout loads these files with next/font/local and serves hashed assets from the app origin. Keep full character coverage for Vietnamese.
